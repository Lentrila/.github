# Lentrila Interactive

### Building high-performance game technology and intelligent, secure systems.

</div>

---

Lentrila Interactive is an independent technology company focused on building
the systems behind the next generation of interactive software.

Our primary focus is game mechanics designed around high-performance
rendering, memory safety, intelligent tooling, security, and low-level
observability.

We work at the intersection of **game technology, systems engineering,
artificial intelligence, and security**.
